# Roadmap

Текущее состояние и планы развития Beholder Eye's.

## Реализовано

- Захват цели в боевом трекере
- Полноценный инвентарь персонажа с отдельным инвентарём денег
- История бросков
- Поиск по справочнику по ключевым словам
- Карточки монстров и персонажей в боевом трекере

## В работе

- Сворачивание лога боя (частично реализовано)

## Планы

### Создание персонажа
- Выпадающий список рас из базы данных
- Выпадающий список классов из базы данных
- Убрать или объяснить служебное поле со значением «1», которое ни на что не влияет
- Сделать форму быстрого создания компактнее: сейчас интерфейс сильно растянут вниз, особенно блок инвентаря

### Боевой трекер
- Оптимизировать раскладку под один и два монитора
- Сделать кнопки инициативы кликабельными, чтобы бросок куба не требовал прокрутки вниз
- Добавить явный маркер смерти персонажа на боевом столе (например, подсветку)

## Известные проблемы

- Состояния (conditions) не применяются к карточкам
